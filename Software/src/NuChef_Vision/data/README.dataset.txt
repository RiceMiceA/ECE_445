This project leverages computer vision and artificial intelligence to identify food ingredients through a camera and recommend appropriate recipes based on the detected items. The system includes a graphical user interface (GUI) to ensure a user-friendly experience.

Key Features:

Real-time recognition of food ingredients using AI

Recipe suggestions tailored to the available ingredients

Intuitive graphical interface for ease of use

Target Audience:
The primary target group for this project is students, particularly those who seek convenient, automated solutions for meal planning.
